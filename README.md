# Stepper Motor Control Using Arduino Uno and L293D

## 📌 Project Overview

This project demonstrates how to control a stepper motor using **Arduino Uno and L293D Motor Driver** in Proteus Design Suite.

The project focuses on controlling the direction of rotation of a stepper motor using digital signals generated by Arduino. Both clockwise and anti-clockwise rotation sequences are implemented.

## 🎯 Objectives

- Understand the working principle of a stepper motor.
- Interface a stepper motor with Arduino Uno.
- Control the motor using the L293D motor driver.
- Implement clockwise and anti-clockwise rotation.
- Understand step sequences using digital HIGH and LOW signals.
- Simulate the circuit using Proteus.

## 🔌 Circuit Connections

### Arduino Uno to L293D

| Arduino Pin | L293D Pin | Function |
|---|---|---|
| D13 | IN1 (Pin 2) | Input 1 |
| D12 | IN2 (Pin 7) | Input 2 |
| D11 | IN3 (Pin 10) | Input 3 |
| D10 | IN4 (Pin 15) | Input 4 |

### L293D Power Connections

| L293D Pin | Connection |
|---|---|
| Pin 1 (EN1) | +5V |
| Pin 9 (EN2) | +5V |
| Pin 16 (VSS) | +5V Logic Supply |
| Pin 8 (VS) | Motor Supply |
| Pins 4, 5, 12, 13 | GND |

**Note:** Arduino GND, L293D GND, and motor power supply GND must be connected together.

## 💻 Arduino Code

### Clockwise Rotation

```cpp
int a = 13;
int b = 12;
int c = 11;
int d = 10;

void setup() {
  pinMode(a, OUTPUT);
  pinMode(b, OUTPUT);
  pinMode(c, OUTPUT);
  pinMode(d, OUTPUT);
}

void loop() {

  // 1010
  digitalWrite(a, HIGH);
  digitalWrite(b, LOW);
  digitalWrite(c, HIGH);
  digitalWrite(d, LOW);
  delay(1000);

  // 0110
  digitalWrite(a, LOW);
  digitalWrite(b, HIGH);
  digitalWrite(c, HIGH);
  digitalWrite(d, LOW);
  delay(1000);

  // 0101
  digitalWrite(a, LOW);
  digitalWrite(b, HIGH);
  digitalWrite(c, LOW);
  digitalWrite(d, HIGH);
  delay(1000);

  // 1001
  digitalWrite(a, HIGH);
  digitalWrite(b, LOW);
  digitalWrite(c, LOW);
  digitalWrite(d, HIGH);
  delay(1000);
}
```

### Anti-Clockwise Rotation

To reverse the rotation direction, reverse the sequence of the four patterns:

`1010 → 1001 → 0101 → 0110`

## 🔄 Step Sequence

| Step | IN1 | IN2 | IN3 | IN4 | Binary Pattern |
|---|---:|---:|---:|---:|---|
| 1 | 1 | 0 | 1 | 0 | 1010 |
| 2 | 0 | 1 | 1 | 0 | 0110 |
| 3 | 0 | 1 | 0 | 1 | 0101 |
| 4 | 1 | 0 | 0 | 1 | 1001 |

The sequence is repeated continuously to rotate the motor.

## 🧠 Working Principle

1. Arduino Uno generates digital HIGH and LOW signals.
2. The L293D receives these signals through its input pins.
3. The motor driver controls the current flowing through the motor windings.
4. The motor rotates according to the applied input sequence.
5. Reversing the input sequence reverses the direction of rotation.
